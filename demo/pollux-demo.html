Load .jsonl files, one JSON object per line. Nothing below is computed until you load a file — no placeholder rows, no numbers without a file behind them.

instructionthe task/prompt text
answerthe response being judged (pairwise rows: answer_1 + answer_2 instead)
scorethe judge's verdict — rows without a numeric score count as unscored, not dropped
judgeoptionaltells files apart in the comparison table; falls back to the file name
scenariooptionalpointwise / rag / sbs / agent — picks the tab "Open in Interactive Judge" opens; defaults to pointwise
criteria_name, criteria_rubricsoptionalshown in the row detail
reference_answer, reasoningoptionalshown in the row detail if present
gold_scoreoptionala human label; enables RMSE / macro F1 / Spearman, and accuracy for pairwise rows

Written in this shape by run_pollux_judge.py / run_selene_judge.py, or by "Score a JSONL batch" above — any file with the same fields works.
